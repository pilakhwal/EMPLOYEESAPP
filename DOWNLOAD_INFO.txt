🚀 HOW TO USE:
================================================================================

1. VIEW SOURCE CODE:
   - Open COMPLETE_SOURCE_DUMP.txt in any text editor
   - All core files are included with complete code
   - Component files are listed in the project structure

2. IMPORT DATA:
   - Login as Admin
   - Go to Settings → Data Backup & Restore
   - Click "Import Data (JSON)"
   - Select DATA_EXPORT.json or your own backup file
   - Data will be restored automatically

3. EXPORT DATA:
   - Login as Admin
   - Go to Settings → Data Backup & Restore
   - Click "Export All Data (JSON)"
   - A JSON file will be downloaded with all your data

4. RUN THE APP:
   - Install dependencies: npm install
   - Start dev server: npm run dev
   - Build for production: npm run build
   - Preview production: npm run preview
